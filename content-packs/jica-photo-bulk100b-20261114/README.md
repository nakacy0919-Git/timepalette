# JICA photo question set B: 100 unpublished drafts

Five countries, 20 questions each: Bhutan, Bolivia, Botswana, Laos, Vietnam.
Each question uses one actual source photo, four text options, an explanation and source URLs.
The 44 photos are reused from set A. These 100 prompts are newly authored; not 100 new photos.

`questions_all.json` is the editorial master, not a directly importable manifest: the current Creator allows five questions per import. The downloadable archive includes 20 compatible import ZIPs.

Status: prepared only. Creator registration: 0. Publication: 0. Source-photo publication rights remain to be reviewed. No production deployment.

The questions cover observation, cultural comparison, geographic sources, communication, evidence and design. Explicit fictional calculations are not local measurements or real prices. The article describes one place and time; questions do not treat it as a national rule.
