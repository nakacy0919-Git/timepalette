# Benin — 29 original draft questions

Adds lifeCulture 9, japanConnection 10 and thinkConnect 10. The live catalog had
one lifeCulture question (cloth dyeing) and no questions in the other two domains.
Together with that existing question, each of the three domains has ten authored
questions. The other three categories use the existing built-in mission sets.

All new questions are Japanese text4 items with an answer, three distractors,
explanation and primary-source URL. Metadata includes elementary, juniorHigh and
highSchoolStandard; it does not claim separately rewritten versions by level.
Historical plans are distinguished from current outcomes; the percentage exercise
explicitly uses fictional data. No third-party images are redistributed.

Sources: UNESCO Gelede and Royal Palaces of Abomey, Japan's Ministry of Foreign
Affairs, Embassy of Japan in Benin and JICA. URLs are retained in each question.
Source review: 2026-11-13 JST. Run build-pack.py to regenerate JSON and six import
ZIPs (five questions per batch, four in the last batch).

Publication status: drafts only. See registration-receipt.json for live UI results.
