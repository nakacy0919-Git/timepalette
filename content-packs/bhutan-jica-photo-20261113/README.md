# Bhutan — JICA World Diary photo drafts (2026-11-13)

Ten original Japanese four-choice questions, each with ONE actual photograph
from JICA Volunteer’s World Diary. Six lifeCulture items supplement the four
currently published Bhutan lifeCulture items; four thinkConnect items practice
separating visible evidence from inference. Existing questions are untouched.
These are drafts only, not a claim of ten published lifeCulture questions.

Every item retains the article title/date, author credit, article URL, original
image URL, explanation, observation/inference distinction and discussion prompt.
The image manifest records original SHA-256 hashes. No AI photographs are used.
The browser importer optimizes the originals to WebP before private draft upload.
Publication rights review remains pending: attribution is not permission, and
no rights-confirmation/publication action is taken by this pack.

Learning metadata selects elementary, juniorHigh and highSchoolStandard. This
is one Japanese question version, not three independently rewritten versions.

Run build-pack.py to reproduce two five-question ZIPs. The script downloads the
explicit source images when absent. Images are persisted in Creator draft media;
they are not committed to the repository. Source facts were read from seven JICA
articles and all ten photographs were visually checked. Both manifests passed
the existing schema validator; ZIPs were checked for image/slot consistency and
image decoding. Registration results are in registration-receipt.json.
