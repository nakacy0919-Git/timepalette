# TimePalette editorial quiz quality standard — wave 1

2026-11-27: existing school bank inventory (1,008): elementary 601, middle 205, high 202. Domains: place 399, language 200, time 201, thinkConnect 200, lifeCulture 5, japanConnection 3. The 4,720 AIA items have not yet been individually audited.

- One unambiguous answer, three same-domain plausible distractors; no answer-length cues, subjective superlatives, or country stereotypes.
- Elementary: concrete experiences, brief stems, complete ruby for Japanese kanji, short accessible English. Middle: contextual knowledge, causes, comparisons and mechanisms. High: source interpretation, institutional distinctions and evidence-based reasoning.
- All content must stand alone, including dates and units when required. Avoid time-sensitive political/economic rankings without reference year and primary evidence.
- Each question contains bilingual options in matching order, one shared answer index, educational explanations in both languages, a country, grade, subcategory, source URL and verification date.
- Categories: customs, culture, food, homes, clothing, languages, history, geography/nature, technology, economy, government/society, education, Japan connections. Map to the existing six game domains to avoid breaking game filters.
- Source-based original writing, not copied questions. Automated checks do not substitute for editorial verification. Review existing questions individually and flag or replace weak template families; do not silently delete existing material.
- Wave 1: 28 new questions; source links and editorial review are included. Browser, build and deployment checks must be performed separately.

## Licensed photography pilot

Prefer real photos from Wikimedia Commons or other original repositories, with file-level permission confirmed. Prefer CC0/public domain or CC BY; CC BY-SA is acceptable with attribution and same-license treatment of image adaptations. Reject NC/ND, unclear rights and misleading images. Record author, title, file page, license and link, display changes, localized alt text and verification date. Protect privacy and check other rights separately. Show answer-revealing images only after submission; never make an image mandatory until fallback and accessibility are designed. This pilot links Wikimedia-hosted images without local copies; verify browser rendering and consider licensed local caching before scaling. Four photographs are associated with eight existing questions.

## 197-country original question production

All four local World Games share the same pool. The Original tab selects the registered editorial catalog; the separate preview tab explicitly includes source-review-pending country-specific draft questions, never silently treating them as approved. The draft factory uses actual distinct culture/heritage descriptions from the 197-country TimePalette atlas, not substituted country names. It chooses comparable category distractors, rejects duplicate options and obvious country-name/answer leakage, and reverses the prompt when possible. It does not certify semantic uniqueness, accuracy, or grade suitability; each question must be human-reviewed against reliable public sources before approval. Candidate photos are metadata only and cannot render until their file-level licensing, factual relevance, and any third-party rights are individually checked. An independently authored elementary/high-school wave is maintained separately. The separate server-hosted online battle endpoint is outside this change.

Wave 2: 197 individually authored, kana-accessible elementary questions (one per country/territory), source/translation review pending. Additionally 12 separately authored middle/high questions based on checked public institutional sources are registered in the approved catalog. The atlas draft generator screens up to 1,002 subject records; rejected records are not counted as questions. The existing reviewed catalog stays available independently; preview is opt-in. 

## Photo coverage wave (2026-11-27)

Reuse the previously reviewed 197-country geography catalog (394 local assets, review date 2026-10-30). Every original question gets at least a clearly labeled country reference photo when a subject-specific photo is not available. Country photos must never be described as depicting the answer. Subject-photo selection uses explicit question IDs/slots and individually checked Commons file metadata; atlas candidates are promoted only when the identical file and caption match a previously reviewed local photo. External new subject files fall back to a local country image after errors. All new subject images are review-only, with original aspect preserved in a 16:9 frame. Do not claim subject-specific coverage equals overall photo coverage. No unreviewed atlas candidate is directly rendered. Existing local assets are reused without copying additional image binaries. Photo permission and question factual approval are independent.
