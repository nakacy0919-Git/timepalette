## 修正・検出した問題

1. キャンベラ周辺の都市選択領域が重なっていた。都市の実位置は点として残し、操作マーカーを離して線で接続。P04/P05/P10の正解都市を都市IDで判定する。
2. Natural Earthにオーストラリアと付属領域が同じISO番号で入っている。最初の本土レコードを代表位置とし、Reactのキーに地名を含める。
3. 古いNatural Earthの首都フラグをそのまま使うと、ブルンジのブジュンブラ座標へ「Gitega」と改名してしまう。Gitegaを明示し、UNGEGNに掲載されたIGEBU提供座標 `[29.93218,-3.42733]` を採用。ベナンはPorto-Novo、ボリビアは憲法上の首都Sucreを明示する。
4. 最初の観察ヒントと既存写真が一致しなかった（アンゴラの写真はカーニバル、アルメニアは屋内、豪州はサンゴ礁など）。画像の実内容から観察文を作成し直した。アンゴラ、アルメニア、ブラジル、ブルンジの写真を差し替えた。
5. ブラジルの旧候補写真のCommons説明はアルゼンチン撮影。ブラジル側国立公園の遊歩道へ変更。アルゼンチンとブラジルの候補写真の重複も解消した。
6. P06の候補に撮影地名を直接表示して答えを漏らさない。作者・ライセンスと写真出典へのリンクを残す。写真が未読込／読込失敗の場合、P06/P07/P09をクリアさせない。
7. 小国・島国を50m地図へ変更。陸上国境のない国では海を隔てた周辺国を扱い、陸上隣国と説明しない。アンゴラのカビンダ、アゼルバイジャンのナヒチェヴァン、西サハラ、フランス領ギアナなどは注記。
8. P02の地図は周辺地域を拡大する。フランスの海外領域やロシア全土に合わせて対象国が極小になるのを避け、国・地域全体の輪郭はカードに示す。
9. Creator公開上限・公開順序・カタログ・表示の各段階で10問上限を削除。処理は既存の管理者承認・公開APIと30件単位の一括処理を維持。11問目以降、動画、音声、Challenge用英語も保持。
10. 旧教材IDを学習の分母・達成数へ数えず、地理の新IDと取得済み公開問題の要約を使う。公開問題の要約キャッシュを出題の代替データとして使わない。

## 検査と根拠

- `npm test`：103テスト、GAS機能検査、Cloudflare SQLite/R2統合検査、PIN権限検査。
- Cloudflare統合検査：同じ国・カテゴリーで12問の公開・順序変更・全文取得を確認。停止後の画像アクセス拒否、作者情報の非公開設定、動画も検査。
- `npm run build`：成功。既存の大きなバンドルと静的／動的import混在の警告は残る。警告ゼロとはしない。
- `npm run qa:geography`：28か国・280問の構造、地図形状、選択肢重複、座標形式、正誤ロジックを検査。内容の事実照合とは別の検査。
- ブラウザ：1024×768と820×1180、各280問の正解・誤答操作、画面内の主要要素、保存後再読み込み、再プレイでIDが増殖しないことを検査。国の輪郭パスはキーボード、カード・マーカー・都市・解答はポインターで操作。実iPad Safariのタッチ検査とは区別する。
- 写真：28点のCommons登録情報とライセンスを取得し、ダウンロード実画像を目視。JSONに作者・ライセンス・Commons出典を保存。
- **外部URLの実ブラウザ読込は未合格**：この環境では管理プロキシの証明書をテストChromiumが信頼せず `ERR_CERT_AUTHORITY_INVALID`。証明書検査は無効化していない。実画像をローカルQA応答として配信した表示検査を行い、外部URLの読込成功とは扱わない。
- Creator4カテゴリーのUI検査：各12問の模擬API応答で表示・分類・学習レベルを検査。ライブDBの約400問を取得・公開した証拠ではない。

国別・問別の結果は `docs/qa/ROUND1_QA_MATRIX.md` およびJSONレポート参照。画面に表示される「制作・検証中」は、外部資料による地理・ルートの内容レビューが残っているため。

## 再現方法

```sh
npm ci
npm test
npm run build
npm run qa:geography
npm run qa:images
npx playwright install --with-deps chromium
npm run qa:browser
npm run qa:release
```

最後のreleaseチェックは、現在は内容確認が未完了のため意図的に失敗する。構造検査の成功を完成判定に転用しない。

この作業環境のブラウザ検査では、インストール済みのテスト用Chromiumを `PLAYWRIGHT_CHROMIUM_EXECUTABLE` で指定し、Commonsから取得した実画像のディレクトリを `QA_CACHED_IMAGES` で指定した。後者を指定した結果は `LOCAL_COMMONS_RENDER_PASS` と記録する。

地理データ再生成は `scripts/build-geography-round1.py --source-dir <directory>`。元データのURL・SHA-256は `src/data/geography/source-manifest.json`。`photo-review.json` の照合済み写真を最後に反映する。再取得したNatural Earthファイルが変化した場合、差分を確認してから採用する。
