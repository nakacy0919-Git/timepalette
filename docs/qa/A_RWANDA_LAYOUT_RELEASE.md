# A-group geography: Rwanda-style workspace — 2026-10-28

The geography category now opens P01 directly for released A countries and Rwanda. The intermediate start button and empty Creator-count page are removed from that path. Countries without a released geography package retain their published catalog.

All ten country missions now share the Rwanda presentation pattern: dark adventure header, learning-level selector, progress/WP panel, persistent P01–P10 navigation and the mission workspace. Portrait uses a compact 5×2 navigation panel. Original Rwanda renderer and factual data are untouched; this does not claim both countries use the same underlying React renderer. Country-specific geography, reviewed photos/credits, capital IDs, points and saved IDs remain intact. No old A/B JSON banks reinstated.

P01 now requires three successful stages: continent → country on a continent map → country among its neighbors. Wrong actions cannot advance or clear. The continent groups reuse the Rwanda prototype and fill omitted country shapes from the reviewed packages. Oceania is centered at 150°E to prevent date-line distortion. Continental placement reference: https://unstats.un.org/unsd/methodology/m49/overview (UN M49; Armenia/Azerbaijan in Asia). Caribbean grouping is the educational North America grouping used by the original prototype.
