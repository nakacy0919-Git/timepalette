# TimePalette activity illustrations

Place the five optimized WebP assets in this folder: `adventure.webp`, `shuffle.webp`, `battle.webp`, `territory.webp`, `journey.webp`. Use the supplied TimePalette artwork pack (800 × 600 px). Images are decorative; the live button labels remain accessible HTML. Until all assets are added, the UI uses its existing mode-specific icon fallback. Do not treat fallback screenshots as approval of the illustrated design.
